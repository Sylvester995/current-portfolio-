# Sylvester McDaniel Kollie — Portfolio

Personal portfolio site for Sylvester McDaniel Kollie, full-stack developer.

A single self-contained `index.html` — no build step, no dependencies (fonts load from Google Fonts).

## Run locally

Just open `index.html` in a browser, or serve it:

```bash
npx serve .
```

## Deploy

Static site — deploys as-is on Vercel, Netlify, or GitHub Pages. No build command or framework preset needed; the output directory is the project root.
